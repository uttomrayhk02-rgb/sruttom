# CRO Landing Page Analyzer

A structured framework for reviewing a landing page from the perspective of conversion clarity, trust, intent, and friction.

## Analysis model

```text
Traffic Intent
     ↓
Message Match
     ↓
Offer Clarity
     ↓
Trust
     ↓
CTA
     ↓
Form / Contact Path
     ↓
Objection Handling
     ↓
Mobile UX
     ↓
Measurement
```

## Review dimensions

| Dimension | Questions |
|---|---|
| Message | Does the visitor immediately understand what is offered? |
| Intent | Does the page match the traffic/search intent? |
| Offer | Is the value proposition specific and credible? |
| Trust | Are reviews, proof, credentials, guarantees, or evidence appropriate? |
| CTA | Is the next action obvious and low-friction? |
| Form | Are fields necessary and easy to complete? |
| Objections | Does the page answer the main reasons someone may hesitate? |
| UX | Is the experience clear on mobile and desktop? |
| Tracking | Can the important actions be measured reliably? |

## Finding format

For every issue:

**Problem → Evidence → Why it matters → Recommendation → Test → KPI**

## Example

**Problem:** CTA competes with several unrelated actions.

**Why it matters:** Choice overload can create friction for high-intent visitors.

**Test:** Make the primary conversion action visually and verbally dominant.

**KPI:** Qualified conversion rate.
