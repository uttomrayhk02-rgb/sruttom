# Marketing Calendar System

A practical planning system for publishing, experiments, client work, and portfolio building.

## Weekly operating calendar

| Day | Focus | Output |
|---|---|---|
| Monday | Research | Market / competitor / audience insights |
| Tuesday | Build | Tool, automation, dashboard, or framework |
| Wednesday | Document | Case study, teardown, or tutorial |
| Thursday | Optimize | Audit, experiment, or improvement |
| Friday | Publish | LinkedIn post + GitHub update |
| Saturday | Review | Performance and lessons |
| Sunday | Plan | Next week's priorities |

## Content workflow

Idea → Research → Build → Test → Document → Publish → Measure → Improve

## Portfolio rule

Every meaningful build should create at least one public artifact:

- README
- screenshot/demo
- workflow
- prompt
- dataset/example
- result or lesson

## Monthly review

Track:

- Projects shipped
- Experiments completed
- GitHub commits
- Useful assets created
- Content published
- Engagement / profile visits
- Leads or opportunities generated
