# Marketing Performance System

A framework for turning raw marketing data into decisions.

## KPI hierarchy

```text
Business Outcome
      ↓
Qualified Leads / Sales
      ↓
Conversion Rate + CPA / ROAS
      ↓
Conversions
      ↓
Clicks + CTR + CPC
      ↓
Impressions + Reach
```

## Google Ads scorecard

| Metric | Question |
|---|---|
| Spend | Is budget aligned with opportunity? |
| CTR | Are ads attracting the right intent? |
| CPC | Is traffic becoming unnecessarily expensive? |
| Conversions | Are meaningful actions happening? |
| CVR | Does traffic convert? |
| CPA | What does each conversion cost? |
| Lead quality | Are conversions commercially useful? |
| ROAS / value | Is spend producing sufficient business value? |

## Diagnostic framework

**Metric changed → Segment → Find cause → Validate → Act → Measure again**

Never optimize from one metric in isolation.

## Weekly review

1. What improved?
2. What declined?
3. Which campaign / query / audience caused the change?
4. Is the issue traffic, conversion, tracking, or economics?
5. What is the highest-impact action for next week?
